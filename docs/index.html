4. Methods & Limitations

Methodology & Pre-Registration

  • Sampling settings: NVIDIA recommended defaults (temperature=1.0, top_p=0.95); max_tokens=1024 (thinking off) or 4096 (thinking on/default).
  • Two-stage sample sizes: Screening at n=50 per cell across 38 conditions × 4 models; escalation to n=300 for core conditions and cells with ≥1 fatal failure.
  • Statistical thresholds: Wilson 95% score intervals, Clopper-Pearson exact intervals, Rule-of-Three upper bounds, and two-sided Fisher exact tests with Holm-Bonferroni correction (α = 0.01).
  • Deterministic grading: Every response is graded by deterministic Python oracles in oracles.py. LLMs never grade test outcomes.

Scope & Limitations

  • Light load only: Requests are paced at ≤40 RPM honoring x-ratelimit-* headers. No stress or load testing was performed.
  • Global serverless routing: Nebius Token Factory public serverless endpoints report region Global; physical serving instances can change without notice.
  • Reference API stack: NVIDIA's integrate.api.nvidia.com endpoint uses a distinct serving configuration and serves as a comparative diagnostic reference rather than ground truth.
  • Not tested: Model general intelligence benchmarks, fine-tuning endpoints, batch jobs, or multi-turn context saturation beyond contract probes.
